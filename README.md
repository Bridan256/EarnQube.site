# EarnQube.site

A simple static landing page for EarnQube.site.

## Files
- `index.html` — main landing page
- `styles.css` — site styling
- `CNAME` — custom domain record
- `robots.txt` — crawler instructions
- `googlee27f065ce1d5dfaa.html` — Google verification file

## Deploy
Host this folder as a static site. For GitHub Pages:
1. Push repository to GitHub.
2. Enable Pages from the repository settings.
3. Use `main` branch and `/ (root)` folder.
4. Set `earnqube.site` as the custom domain.

## Notes
- External call-to-action links point to `mulaprime.com` and `qashflux.com`.
- SEO metadata and social sharing tags are included.
